# تدفق المستخدم — AI Context Builder

## 1. تجربة الاستخدام الأولى

```text
فتح الإضافة لأول مرة
  → شاشة ترحيب عربية مختصرة
  → شرح أن البيانات محفوظة محلياً
  → زر إنشاء أول مشروع
  → نموذج مشروع جديد
  → حفظ المشروع
  → عرض لوحة المشاريع
```

## 2. إنشاء مشروع جديد

1. يضغط المستخدم زر **مشروع جديد**.
2. يختار قالباً جاهزاً أو يبدأ من نموذج فارغ.
3. يملأ الحقول الأساسية:
   - اسم المشروع.
   - الوصف.
   - التقنيات.
   - الأهداف.
   - المتطلبات.
   - تعليمات الذكاء الاصطناعي.
   - الملاحظات.
4. يضغط **حفظ المشروع**.
5. تظهر رسالة نجاح.
6. يعود المستخدم إلى قائمة المشاريع أو ينتقل إلى معاينة السياق.

## 3. استخدام قالب جاهز

```text
مشروع جديد
  → اختيار قالب
  → تعبئة حقول إرشادية تلقائياً
  → تعديل المستخدم للنصوص
  → حفظ
```

القالب لا يمنع التعديل، بل يوفر بداية سريعة فقط.

## 4. البحث بين المشاريع

1. يفتح المستخدم Popup.
2. يكتب في مربع البحث.
3. تظهر النتائج المطابقة فورياً.
4. يمكنه فتح المشروع أو جعله نشطاً أو معاينة سياقه.

## 5. معاينة وبناء السياق

```text
اختيار مشروع
  → فتح صفحة/تبويب المعاينة داخل Popup
  → توليد السياق تلقائياً
  → عرض Prompt منظم
  → نسخ يدوي أو تعيين كمشروع نشط
```

## 6. الإدراج داخل ChatGPT أو Claude أو Gemini

1. يفتح المستخدم إحدى المنصات المدعومة.
2. يلاحظ ظهور زر **إدراج سياق المشروع** قرب منطقة الإدخال.
3. يضغط الزر.
4. إذا كان هناك مشروع نشط:
   - يتم إدراج السياق مباشرة.
5. إذا لم يكن هناك مشروع نشط:
   - تظهر قائمة اختيار سريعة.
   - يختار المستخدم المشروع.
   - يتم إدراج السياق.
6. تظهر رسالة نجاح قصيرة.
7. لا يتم إرسال الرسالة تلقائياً؛ المستخدم يراجع النص ثم يرسل بنفسه.

## 7. تعديل مشروع

```text
قائمة المشاريع
  → اختيار مشروع
  → تعديل
  → تحديث الحقول
  → حفظ
  → تحديث updatedAt
  → إعادة توليد السياق عند المعاينة
```

## 8. حذف مشروع

1. يضغط المستخدم حذف.
2. يظهر تأكيد واضح باللغة العربية.
3. عند التأكيد يتم حذف المشروع من IndexedDB.
4. إذا كان المشروع المحذوف هو المشروع النشط، يتم مسح `activeWorkspaceId`.

## 9. التصدير

```text
الإعدادات أو أدوات البيانات
  → تصدير المشاريع
  → قراءة المشاريع من IndexedDB
  → بناء ملف JSON
  → تنزيل الملف على جهاز المستخدم
```

## 10. الاستيراد

```text
الإعدادات أو أدوات البيانات
  → استيراد JSON
  → اختيار ملف
  → التحقق من البنية
  → عرض ملخص العناصر الصالحة
  → دمج البيانات
  → رسالة نجاح أو أخطاء واضحة
```

## 11. حالات الخطأ المهمة

| الحالة | الرسالة المقترحة |
|---|---|
| لا توجد مشاريع | لا توجد مشاريع بعد. أنشئ مشروعك الأول للبدء. |
| فشل قراءة قاعدة البيانات | تعذر الوصول إلى التخزين المحلي. أعد فتح الإضافة. |
| ملف JSON غير صالح | الملف المحدد غير صالح أو لا يتبع بنية AI Context Builder. |
| لم يتم العثور على مربع الإدخال | تعذر العثور على مربع الكتابة في هذه الصفحة. حاول تحديده يدوياً. |
| مشروع بلا اسم | اسم المشروع مطلوب قبل الحفظ. |

## 12. مبادئ تجربة المستخدم

- النصوص قصيرة وواضحة.
- لا توجد مصطلحات تقنية غير ضرورية في الواجهة.
- كل إجراء خطير يحتاج تأكيداً.
- لا يتم الإرسال التلقائي إلى نموذج الذكاء الاصطناعي.
- الخصوصية مذكورة بوضوح داخل شاشة البداية وأدوات التصدير.
