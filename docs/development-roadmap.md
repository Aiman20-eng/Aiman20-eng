# خارطة طريق التطوير — AI Context Builder

## المرحلة 0 — اعتماد التصميم

**الهدف:** مراجعة الوثائق قبل كتابة الكود.

### المخرجات

- وثيقة متطلبات المنتج.
- وثيقة معمارية النظام.
- مخطط قاعدة البيانات.
- تدفق المستخدم.
- هيكل المجلدات.
- خارطة الطريق.

### معايير الانتقال

- اعتماد نطاق الإصدار الأول.
- اعتماد الحقول الأساسية للمشروع.
- اعتماد التخزين المحلي فقط.
- اعتماد المنصات المدعومة أولياً.

## المرحلة 1 — تأسيس المشروع

**الهدف:** إعداد مشروع React + TypeScript + Tailwind CSS + Manifest V3.

### المهام

- إعداد Vite أو أداة بناء مناسبة للإضافة.
- إعداد TypeScript.
- إعداد Tailwind CSS مع RTL.
- إعداد Manifest V3.
- إعداد نقاط الدخول: Popup وContent Script وBackground.
- إعداد اختبارات أساسية.

### المخرجات

- إضافة قابلة للبناء والتثبيت يدوياً في Chrome وEdge.
- شاشة Popup أولية عربية.

## المرحلة 2 — طبقة التخزين والأنواع

**الهدف:** بناء أساس IndexedDB وأنواع الدومين.

### المهام

- تعريف أنواع `Workspace` و`AppSetting`.
- تنفيذ `indexedDbClient`.
- تنفيذ `workspaceRepository`.
- تنفيذ `settingsRepository`.
- إضافة اختبارات للخدمات القابلة للاختبار.

### المخرجات

- CRUD محلي مستقر للمشاريع.
- إعداد المشروع النشط.

## المرحلة 3 — إدارة المشاريع

**الهدف:** تمكين المستخدم من إنشاء وتعديل وحذف المشاريع.

### المهام

- بناء قائمة المشاريع.
- بناء نموذج المشروع.
- بناء صفحة التفاصيل أو المعاينة.
- تنفيذ البحث.
- تنفيذ رسائل النجاح والخطأ.

### المخرجات

- تجربة كاملة لإدارة المشاريع داخل Popup.

## المرحلة 4 — بناء السياق والقوالب

**الهدف:** توليد Prompt احترافي منظم.

### المهام

- تنفيذ `contextBuilderService`.
- بناء قوالب Laravel وFlutter وReact وNode.js وSaaS وContent Creation.
- إضافة معاينة السياق.
- إضافة زر نسخ السياق.
- إضافة اختبارات لخدمة بناء السياق.

### المخرجات

- Prompt عربي منظم وقابل للنسخ أو الإدراج.

## المرحلة 5 — الاستيراد والتصدير

**الهدف:** تمكين النسخ الاحتياطي المحلي.

### المهام

- تنفيذ تصدير JSON.
- تنفيذ استيراد JSON.
- التحقق من بنية الملف.
- عرض ملخص نجاح أو فشل الاستيراد.
- إضافة اختبارات للاستيراد والتصدير.

### المخرجات

- ملف JSON قابل للحفظ والاستعادة.

## المرحلة 6 — الإدراج بنقرة واحدة

**الهدف:** إدراج السياق داخل منصات الذكاء الاصطناعي.

### المهام

- تنفيذ اكتشاف المنصة.
- تنفيذ Adapter لكل منصة.
- حقن زر عربي داخل الصفحة.
- قراءة المشروع النشط.
- إدراج Prompt في مربع الكتابة.
- إضافة معالجة أخطاء واضحة.

### المخرجات

- إدراج يعمل على ChatGPT وClaude وGemini دون إرسال تلقائي.

## المرحلة 7 — الصقل والجودة

**الهدف:** تحسين الأداء والتجربة والاستقرار.

### المهام

- مراجعة RTL والتجاوب.
- تحسين حالات الفراغ والأخطاء.
- مراجعة الصلاحيات.
- اختبار يدوي على Chrome وEdge.
- مراجعة عدم وجود اتصالات خارجية.
- تحسين حجم الحزمة.

### المخرجات

- إصدار أول قابل للاستخدام الفعلي.

## المرحلة 8 — التحضير للإصدار

**الهدف:** تجهيز الحزمة والنشر اليدوي أو الرفع للمتاجر لاحقاً.

### المهام

- إعداد أيقونات المنتج.
- تجهيز وصف المتجر باللغة العربية.
- كتابة سياسة خصوصية بسيطة توضح التخزين المحلي.
- تجهيز ملف ZIP للإضافة.
- توثيق طريقة التثبيت اليدوي.

### المخرجات

- حزمة إصدار أول.
- توثيق تثبيت واستخدام.

## أولويات ما بعد الإصدار الأول

- Dark Mode.
- تصنيفات ووسوم للمشاريع.
- قوالب مخصصة من المستخدم.
- اختصارات لوحة مفاتيح.
- دعم Perplexity وPoe ومنصات أخرى.
- مزامنة اختيارية مشفرة بعد موافقة واضحة من المستخدم.
